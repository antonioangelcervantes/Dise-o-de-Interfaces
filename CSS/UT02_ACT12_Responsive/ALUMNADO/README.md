# UT02_ACT12 · Diseño responsive con CSS

**Módulo:** Desarrollo de Interfaces Web · 2.º DAW  
**Material:** alumnado

## Qué contiene esta carpeta

- `UT02_ACT12_Responsive.md`: explicaciones, ejemplos y dos predicciones.
- `UT02_ACT12_Responsive.pdf`: copia del documento teórico para consulta sin conexión.
- `ENUNCIADOS.md`: dos laboratorios y el reto final autónomo.
- `laboratorios/lab01-mediaqueries/`: primera práctica de media queries.
- `laboratorios/lab02-grid-flex/`: práctica de Grid y Flexbox responsive.
- `proyecto-final/RESPONSIVE_PLANTILLA.md`: modelo vacío de documentación para copiar en tu CampusHub.

## Cómo trabajar

1. Lee los apartados teóricos y **responde las predicciones antes de probar código**.
2. Completa las prácticas desde sus archivos de partida; ninguna incluye las reglas responsive resueltas.
3. Realiza el reto final **sobre tu propio CampusHub terminado de ACT11**. No existe una plantilla nueva del proyecto.
4. Entrega tu CampusHub actualizado, con `RESPONSIVE.md` y las capturas solicitadas.

**Herramientas:** Visual Studio Code, Live Server y Chrome DevTools. No necesitas conexión a Internet para realizar los laboratorios.
